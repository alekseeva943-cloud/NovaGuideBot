# КИБЕРБЕЗОПАСНОСТЬ И ЭТИЧНЫЙ ХАКИНГ

## Введение
Кибербезопасность — это область, связанная с защитой информационных систем, сетей, приложений и данных от несанкционированного доступа, атак, утечек информации и цифровых угроз.
Основные задачи кибербезопасности:
* защита данных
* защита инфраструктуры
* обеспечение стабильной работы систем
* предотвращение атак
* обнаружение угроз
* контроль доступа
# ОСНОВНЫЕ ПРИНЦИПЫ БЕЗОПАСНОСТИ
## Конфиденциальность
Доступ к данным должны иметь только авторизованные пользователи.
Методы защиты:
* шифрование
* VPN
* контроль доступа
* двухфакторная аутентификация
## Целостность
Информация не должна изменяться без разрешения.
Методы:
* хеширование
* цифровые подписи
* контроль изменений
* журналирование
## Доступность
Системы и сервисы должны быть доступны пользователям.
Методы:
* резервирование
* backup
* защита от DDoS
* отказоустойчивая инфраструктура
# ОСНОВНЫЕ УГРОЗЫ
## Malware
Вредоносное программное обеспечение, предназначенное для нанесения ущерба системе или получения несанкционированного доступа.
Основные типы:
* вирусы
* трояны
* ransomware
* spyware
* worms
* keyloggers
## Phishing
Метод социальной инженерии, направленный на кражу:
* логинов
* паролей
* банковских данных
* токенов доступа
## DDoS
Атака, направленная на перегрузку сервера или сервиса большим количеством запросов.
Цели атаки:
* нарушение доступности
* перегрузка инфраструктуры
* вывод сервиса из строя
## MITM
Man-in-the-Middle — атака, при которой злоумышленник перехватывает трафик между сторонами.
# ЭТИЧНЫЙ ХАКИНГ
## White Hat Hacker
Этичный хакер — специалист по информационной безопасности, который ищет уязвимости с разрешения владельца системы.
Основные задачи:
* penetration testing
* security assessment
* анализ уязвимостей
* аудит безопасности
## Методология Ethical Hacking
### Reconnaissance
Сбор информации о цели.
Методы:
* OSINT
* WHOIS
* DNS enumeration
* Google Dorks
### Scanning
Поиск:
* открытых портов
* сервисов
* версий ПО
* уязвимостей
### Gaining Access
Эксплуатация обнаруженных уязвимостей.
### Maintaining Access
Закрепление доступа в системе.
### Covering Tracks
Сокрытие следов активности.
# ИНСТРУМЕНТЫ
## Nmap
Инструмент для анализа сети и сканирования портов.
Возможности:
* поиск хостов
* определение открытых портов
* определение ОС
* определение версий сервисов
Пример:
```bash id="m2v6qk"
nmap -sV target.com
```
---
## Wireshark
Инструмент для анализа сетевого трафика.
Используется для:
* анализа пакетов
* мониторинга сети
* выявления аномалий
* forensic-анализа
## Burp Suite
Инструмент для тестирования безопасности веб-приложений.
Основные модули:
* Proxy
* Repeater
* Intruder
* Scanner
## Metasploit
Платформа для тестирования безопасности и анализа уязвимостей.
Используется для:
* exploitation
* post-exploitation
* payload management
# ВЕБ-УЯЗВИМОСТИ
## SQL Injection
SQL-инъекция — тип веб-уязвимости, позволяющий вмешиваться в SQL-запросы приложения.
Основные риски:
* утечка данных
* обход аутентификации
* получение доступа к базе данных
Методы защиты:
* Prepared Statements
* ORM
* валидация ввода
* ограничение привилегий
## XSS
Cross-Site Scripting — внедрение вредоносного JavaScript-кода в веб-страницу.
Типы XSS:
* Reflected XSS
* Stored XSS
* DOM-based XSS
Методы защиты:
* escaping
* sanitization
* CSP
* HttpOnly cookies
## CSRF
Cross-Site Request Forgery — атака, заставляющая пользователя выполнить действие без его намерения.
Методы защиты:
* CSRF tokens
* SameSite cookies
* повторная аутентификация
# БЕЗОПАСНОСТЬ API
Основные меры защиты API:
* Rate Limiting
* валидация ввода
* JWT с коротким сроком жизни
* контроль доступа
* логирование
* audit trails
# ПАРОЛИ И АУТЕНТИФИКАЦИЯ
Рекомендации:
* использовать сложные пароли
* не повторять пароли
* использовать password manager
* включать MFA / 2FA
Менеджеры паролей:
* Bitwarden
* KeePass
* 1Password
# ШИФРОВАНИЕ
## Симметричное шифрование
Использует один ключ для шифрования и расшифровки.
Примеры:
* AES
* ChaCha20
## Асимметричное шифрование
Использует открытый и закрытый ключ.
Примеры:
* RSA
* ECC
## Хеширование
Одностороннее преобразование данных.
Примеры:
* SHA-256
* bcrypt
* Argon2
# SIEM И SOC
## SIEM
Security Information and Event Management — система мониторинга и анализа событий безопасности.
Основные функции:
* сбор логов
* корреляция событий
* обнаружение угроз
* alerting
Примеры:
* Splunk
* ELK Stack
* Wazuh
## SOC
Security Operations Center — центр мониторинга и реагирования на инциденты безопасности.
Основные роли:
* SOC Analyst
* Incident Responder
* Threat Hunter
# BUG BOUNTY
Bug Bounty — программа поиска уязвимостей за вознаграждение.
Популярные платформы:
* HackerOne
* Bugcrowd
* YesWeHack
* Intigriti
# ТЕРМИНОЛОГИЯ
## Exploit
Код или инструмент для использования уязвимости.
## Payload
Код, выполняемый после эксплуатации уязвимости.
## Backdoor
Скрытый способ доступа к системе.
## Rootkit
Инструмент для сокрытия следов активности.
## Zero-day
Неизвестная разработчику уязвимость.
## IOC
Индикатор компрометации системы.
## TTP
Тактики, техники и процедуры злоумышленников.
# ПРАКТИЧЕСКИЕ ПЛАТФОРМЫ
Для обучения и практики используются:
* Hack The Box
* TryHackMe
* PortSwigger Academy
* OverTheWire
# ЗАКОН И ЭТИКА
Тестирование безопасности должно выполняться:
* только легально
* только с разрешения владельца системы
* только в рамках ethical hacking
* только в образовательных или рабочих целях
Незаконное использование инструментов и методов может нарушать законодательство.
